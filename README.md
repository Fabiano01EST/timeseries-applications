# 📊 Análise de Séries Temporais em R

Este repositório apresenta uma aplicação de **análise de séries temporais em R**, com foco na identificação de tendências, sazonalidade e geração de previsões a partir de dados observados ao longo do tempo. São utilizadas técnicas de modelagem e decomposição para compreender o comportamento da série e apoiar a tomada de decisão.

As análises são desenvolvidas com pacotes como `forecast`, `tsibble` e `fable`, permitindo modelagem, ajuste e avaliação de desempenho preditivo.

O projeto pode ser aplicado a dados econômicos, empresariais ou ambientais, servindo como material de estudo em Estatística e Ciência de Dados.
